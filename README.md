# Library Book Inventory Management

A Java console application to manage library books.

## Features
- Add, update, delete, and search books.
- Validates string inputs to not be empty and checks if publication year is valid.

## How to Compile and Run
```bash
javac src/*.java
java -cp src Main
```

## How to Test
```bash
javac src/*.java
java -cp src TestBookService
```
